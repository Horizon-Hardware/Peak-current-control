## 1. 项目概况

- 芯片：STM32G474CBT6（LQFP48）
- 工具链：STM32CubeMX 生成 + CMake + CLion + arm-none-eabi-gcc
- 关键外设：HRTIM1、ADC1/ADC2（双 ADC 同步模式）、OPAMP3/4、COMP2/3、DAC1、FDCAN3
- 引脚：
  - HRTIM 输出：PA8(TA1)、PA9(TA2)、PA10(TB1)、PA11(TB2)

  - ADC：ADC1 CH3(PA2)、CH11(PB12=OPAMP4 输出)；ADC2 CH13(PA5)、CH3(PA6)、CH2(PA1)、CH17(PA4)

## 2. HRTIM 主定时器中断

### 问题
主定时器（Master）中断进不去，断点不命中。

### 根因
启动函数传错常量。`main.c` 中：

```c
// 错误：传了「定时器索引」HRTIM_TIMERINDEX_MASTER（= 0x6）
HAL_HRTIM_WaveformCounterStart(&hhrtim1, HRTIM_TIMERINDEX_MASTER);
```

`HAL_HRTIM_WaveformCounterStart` 内部是 `MCR |= Timers`，需要的是**定时器 ID**（位掩码）：

| 宏 | 值 | 含义 |
|---|---|---|
| `HRTIM_TIMERINDEX_MASTER` | `0x6` | 寄存器访问索引（不是使能位） |
| `HRTIM_TIMERID_MASTER` | `0x00010000`（MCEN） | MCR 主计数器使能位 bit16 |

`MCR |= 0x6` 只动了时钟预分频位，没置 MCEN，主计数器不计数 → 无 MREP 重复中断。

### 修复
```c
HAL_HRTIM_WaveformCounterStart(&hhrtim1, HRTIM_TIMERID_MASTER);
```

### 验证
- `HRTIM1->sMasterRegs.MCR` bit16（MCEN）= 1
- `HRTIM1->sMasterRegs.MCNTR` 递增

## 3. 弱回调函数

### 概念
HAL 的 `__weak` 弱回调，用**相同签名重新定义**即可覆盖（非 C++ virtual）。

### 主定时器重复事件回调
中断处理实际调用（`stm32g4xx_hal_hrtim.c:10546`）：

```c
HAL_HRTIM_RepetitionEventCallback(hhrtim, HRTIM_TIMERINDEX_MASTER);
```

覆盖写法（放 `main.c` 的 `USER CODE BEGIN 4`）：

```c
void HAL_HRTIM_RepetitionEventCallback(HRTIM_HandleTypeDef *hhrtim, uint32_t TimerIdx)
{
  if (TimerIdx == HRTIM_TIMERINDEX_MASTER)
  {
    /* 每个开关周期触发一次，放控制逻辑 */
  }
}
```

> 注意：库里弱函数注释写的 `HAL_HRTIM_Master_RepetitionEventCallback` 是过时注释，
> 该函数不存在，真正生效的是 `HAL_HRTIM_RepetitionEventCallback`。
> `USE_HAL_HRTIM_REGISTER_CALLBACKS = 0`，走「重写弱函数」路径，不需要注册。

## 4. CMake 构建问题

### 问题
`multiple definition of 'xxx'` —— 同一个 `User/*.c` 被编译了两次。

### 根因
用户源文件同时出现在两个 CMakeLists：
- 顶层 `CMakeLists.txt` 的 `add_executable(...)`
- `cmake/stm32cubemx/CMakeLists.txt` 的 `add_library(STM32_Drivers OBJECT ...)`

两个 `.obj` 都链接进 elf → 符号重复。

### 修复（重要规则）
**自己写的 `User/` 源文件，只加在顶层 `CMakeLists.txt` 的 `add_executable` 里，
永远不要动 `cmake/stm32cubemx/CMakeLists.txt`。**

`cmake/stm32cubemx/CMakeLists.txt` 是 CubeMX 自动生成的，重新生成会覆盖。
删掉其中 `add_library(stm32cubemx INTERFACE ...)` 和
`add_library(STM32_Drivers OBJECT ...)` 里的 `../../User/*.c` 即可。

先后遇到 `bsp_dwt.c`、`task.c` 两次同样问题，均已按此修复。

## 5. DWT 周期计数器

文件：`User/bsp_dwt.c`（基于 Cortex-M DWT CYCCNT 的高精度时间工具集）

### 功能速览

| 函数 | 功能 |
|---|---|
| `DWT_Init(MHz)` | 使能 DWT、清零并启动 CYCCNT、缓存 Hz/ms/us 三档计数值 |
| `DWT_SysTimeUpdate()` | 刷新 64 位时间线 → 拆成 SysTime(s/ms/us) |
| `DWT_GetTimeline_s/ms/us()` | 绝对时间（秒/毫秒/微秒） |
| `DWT_GetDeltaT(cnt_last)` | 相对上次记录点时间差（秒，float），自动更新基准 |
| `DWT_GetDeltaT64(cnt_last)` | 同上，double 精度 |
| `DWT_Delay_us/ms/s()` | 阻塞延时 |
| `DWT_Set_Timeout / Check_Timeout` | 无阻塞超时 |
| `DWT_Profile_Start / Stop` | 代码段耗时测量 |

### 关键点
- `DWT->CYCCNT` 是 32 位 CPU 周期计数器，170MHz 下约 25s 回绕一次。
- 用 `CYCCNT_RoundCount` 记录溢出次数，扩展成 64 位时间线。
- **必须周期性调用 `DWT_SysTimeUpdate()`**（建议放 SysTick 中断），否则溢出轮数漏记、时间跳变。

## 6. 测量定时器中断周期

用 `DWT_GetDeltaT64` 在 HRTIM 主重复回调里测两次中断间隔：

```c
static uint32_t s_isr_last_cnt = 0;
volatile double g_isr_period_us = 0.0;

void HAL_HRTIM_RepetitionEventCallback(HRTIM_HandleTypeDef *hhrtim, uint32_t TimerIdx)
{
  if (TimerIdx == HRTIM_TIMERINDEX_MASTER)
  {
    if (s_isr_last_cnt == 0)
      s_isr_last_cnt = DWT->CYCCNT;      // 首次只记基准
    else
      g_isr_period_us = DWT_GetDeltaT64(&s_isr_last_cnt) * 1e6;  // 秒→微秒
  }
}
```

### 理想中断间隔
```
计数时钟 = 170 MHz × 32(MUL32) = 5.44 GHz
中断周期 = Period / 计数时钟 = 27200 / 5.44 GHz = 5.0 µs
频率     = 200 kHz
```
- `RepetitionCounter = 0` → 每周期触发一次 MREP。
- 换算公式：`Period = 5.44e9 / 目标频率`（例：200kHz → 27200）。
- Watch 窗口看 `g_isr_period_us`，应 ≈ 5.0。

## 7. 内部运放 + ADC 采样

### 关键：Init ≠ 上电
`MX_OPAMPx_Init()`（`HAL_OPAMP_Init`）只配置，**上电需 `HAL_OPAMP_Start`**（置 `OPAMP_CSR_OPAMPxEN`）。

```c
HAL_OPAMP_Start(&hopamp4);   // 跟随器：PB11 → PB12（PB12 = ADC1_IN11）
HAL_OPAMP_Start(&hopamp3);   // 电容电压跟随器
```

### ADC 采样（双 ADC 同步 + DMA）
ADC1/ADC2 是 `ADC_DUALMODE_REGSIMULT`（同步），DMA 一次传 32 位（高16=ADC2，低16=ADC1）。

```c
#define ADC_CH_NUM 2
static uint32_t adc_dma_buf[ADC_CH_NUM];   // 32位：高16 ADC2，低16 ADC1

HAL_ADC_Start_DMA(&hadc1, (uint32_t*)adc_dma_buf, ADC_CH_NUM);  // 只启动主 ADC

uint16_t adc1_val = (uint16_t)(adc_dma_buf[i] & 0xFFFF);
uint16_t adc2_val = (uint16_t)(adc_dma_buf[i] >> 16);
```

通道映射：
| i | ADC1（低16位） | ADC2（高16位） |
|---|---|---|
| 0 | CH3（PA2） | CH13（PA5） |
| 1 | CH11（PB12 = OPAMP4 输出） | CH3（PA6） |

> 注意：ADC1 配 2 通道、ADC2 配 4 通道，同步模式下转换次数由主 ADC 决定（=2），
> ADC2 的 rank3/rank4 不会被转换。

## 8. 相移交错 + ADC 中点采样

### 相移（交错并联）减纹波
两相错 180°，电感纹波叠加抵消，减小输入/输出电容纹波电流和 EMI。

HRTIM 实现：
- Master 定时器 = 公共时基，MCMP1 = Period/2（=13600，180° 标记）。
- Timer A：`ResetTrigger = HRTIM_TIMRESETTRIGGER_MASTER_PER`（0° 复位）
- Timer B：`ResetTrigger = HRTIM_TIMRESETTRIGGER_MASTER_CMP1`（180° 复位）
- A/B 周期 = Master 周期。

```c
pTimerCfg.ResetTrigger = HRTIM_TIMRESETTRIGGER_MASTER_PER;   // Timer A
pTimerCfg.ResetTrigger = HRTIM_TIMRESETTRIGGER_MASTER_CMP1;  // Timer B
```

### ADC 中点采样（降噪）
采样点离开关边沿越远噪声越小；三角波中点 = 平均电流。

- HRTIM 4 个 ADC 触发单元（TRG1~4），事件选在采样时刻：

```c
HRTIM_ADCTriggerCfgTypeDef adcTrig = {0};
adcTrig.UpdateSource = HRTIM_ADCTRIGGERUPDATE_TIMER_A;
adcTrig.Trigger      = HRTIM_ADCTRIGGEREVENT13_TIMERA_CMP3;  // CMP3 当采样点
HAL_HRTIM_ADCTriggerConfig(&hhrtim1, HRTIM_ADCTRIGGER_1, &adcTrig);
```

- ADC 侧改外部触发、关连续模式：

```c
hadc1.Init.ExternalTrigConv      = ADC_EXTERNALTRIG_HRTIM_TRG1;
hadc1.Init.ExternalTrigConvEdge  = ADC_EXTERNALTRIGCONVEDGE_RISING;
hadc1.Init.ContinuousConvMode    = DISABLE;
hadc1.Init.DMAContinuousRequests = DISABLE;
```

- 采样点选择：平均电流 → ON 时间中点（`duty×Period/2`）；峰值电流 → ON 结束（`duty×Period`）。

## 9. 无波形输出问题

### 根因
`main.c` 只启动了 Master 计数器：

```c
HAL_HRTIM_WaveformCounterStart(&hhrtim1, HRTIM_TIMERID_MASTER);  // 只置 MCEN
```

TA1/TB1 的「置低」依赖 Timer A/B 的 CMP1 比较事件，但 TACEN/TBCEN 未使能，
Timer A/B 不计数 → CMP1 永不触发 → 输出置高后永不拉低 → 引脚恒高，无波形。

### 修复
```c
HAL_HRTIM_WaveformCounterStart(&hhrtim1,
    HRTIM_TIMERID_MASTER | HRTIM_TIMERID_TIMER_A | HRTIM_TIMERID_TIMER_B);
```

### 附带提醒
- TA2/TB2 的 `SetSource/ResetSource` 设为 `NONE`（关闭状态），要做半桥互补需补配。
- `main.c` 里 `CMP_A = CMP_B = 0.2*PERIOD = 5440`（20% 占空比）会覆盖 hrtim.c 的 13600（50%）。
